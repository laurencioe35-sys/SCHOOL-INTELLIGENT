# Quality Gates

G0 Requisitos identificados.
G1 Arquitectura compatible.
G2 Código consistente con contratos.
G3 Lint/type-check.
G4 Unit/integration tests.
G5 E2E en flujos críticos.
G6 Security review.
G7 Migraciones verificadas.
G8 Performance cuando aplique.
G9 Observabilidad.
G10 Documentación.
G11 Build reproducible.
G12 Evidencia/checkpoint.

Compilar no equivale a completar una tarea.
