# Beamforming

El firmware usa delay-and-sum por presupuesto de computo. El modulo local
expone estimacion de direccion, combinacion de canales y SNR. La validacion
contra un array MEMS real, eco de aula, AEC y comparacion contra STT queda
pendiente hasta disponer del hardware y una grabacion autorizada; las pruebas
unitarias no se presentan como evidencia acustica de produccion.
