# Seguridad

- Secretos únicamente mediante variables de entorno.
- Contraseñas con hash Argon2.
- Tokens JWT con expiración.
- Autorización RBAC en backend.
- Aislamiento obligatorio por tenant.
- Validación Pydantic de entradas.
- Auditoría para operaciones críticas.
- CORS restringido por configuración.
